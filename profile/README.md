### About Me

I'm starting my journey into digital hardware design, RTL engineering, and VLSI. Right now, I'm focused on understanding how logic gates scale up into full processors and learning the tools used to simulate and synthesize hardware.

- **Currently learning:** SystemVerilog, digital logic design, finite state machines (FSMs), and basic RISC-V architecture
- **Tools I'm exploring:** Yosys, Icarus Verilog (`iverilog`), Verilator, and GTKWave
- **Hardware:** Experimenting with microcontrollers and entry-level FPGA boards
- **Other interests:** Low-level C programming, Linux command-line workflows, and custom tooling

- Writing clean, synthesizable combinational and sequential logic in SystemVerilog

- Studying computer architecture fundamentals and instruction set execution
